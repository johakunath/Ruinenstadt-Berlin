# Ruinenstadt Berlin

3D-Loot-ARPG im Berlin nach dem Zusammenbruch. Stand: Gate 1, ein Köpenicker Hinterhof bei Nacht.

Spielen: https://johakunath.github.io/Ruinenstadt-Berlin/

| | Tastatur und Maus | Controller | Touch |
|---|---|---|---|
| Laufen | WASD | Linker Stick | Linke Bildhälfte |
| Schlagen | Linke Maustaste oder J | X | Schlag |
| Rollen | Leertaste oder rechte Maustaste | A | Rolle |
| Kraft | E | B | Kraft |
| Ultimativ | R | LB | Ultimativ |
| Inventar | I / Tab | Y | Inventar |
| Optionen | Esc | Start | ☰ |

```bash
npm install
```

```bash
npm run dev
```
