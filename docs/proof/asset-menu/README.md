The first desktop intro screenshot was captured after pressing Losziehen in the game. The live camp screenshot was captured after using the Kommandantur station ring in the 3D map. The other screenshots use the shipped UI components with review fixtures for intro navigation, Kodex discoveries and camp rescues. Chromium decoded all four intro images, 30 normal and boss portraits and seven station portraits. The desktop captures are 1280 × 720 and the touch capture is 844 × 390.

The thirteen new enemy portraits and Ilse follow the existing 2D busts on dark teal. The other six keeper portraits are shared assets already in the Kodex. The four intro paintings follow the Köpenick board and the existing card text.
